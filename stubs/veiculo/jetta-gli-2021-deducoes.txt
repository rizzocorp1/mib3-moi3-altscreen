# ---- os números acompanham a unidade escolhida na tela (item 2 do roteiro, 12/10/2026)
# No carro, quem manda a distância, a velocidade média, o consumo e a autonomia é o painel, e manda
# com a unidade dentro da mensagem: a central mostra o que recebe. (A temperatura de fora é a
# exceção: a central converte sozinha.) Quando a tela troca a unidade em Unidades, é o painel que
# passa a mandar outro número e outra unidade. Aqui o carro de mentira faz esse papel com os
# marcadores @de e @se (cabeçalho do driver/veiculostub.c), que leem a unidade guardada a cada envio.
# SIMULAÇÃO: que o painel responde assim é dedução, sem carro para medir. O código da unidade é
# copiado tal qual, porque as duas pontas usam a mesma tabela do firmware (CarConstants:
# DISTANCEUNIT_KM 0 e _MI 1; SPEEDUNIT_KMPH 0 e _MPH 1; CONSUMPTIONUNIT_LP100KM 0, _KMPL 1,
# _MPG_UK 3 e _MPG_US 4). O único número refeito é a autonomia: os 400 km de simulação lá de cima
# viram 249 mi. Os outros são zero ou não existem (carro parado, médias sem medida).
[DSICarKombi.updateBCCurrentRange1]
currentRange.currentRangeValue = @se DSICarTimeUnitsLanguage.updateDistanceUnit.distanceUnit 1:249 senao 400
currentRange.currentRangeUnit = @de DSICarTimeUnitsLanguage.updateDistanceUnit.distanceUnit
